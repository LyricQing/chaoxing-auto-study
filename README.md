# chaoxing-auto-study

一个 TRAE 技能（Skill），用 computer-use 驱动**你自己已登录的浏览器**，自动完成超星学习通（mooc1.chaoxing.com）的课程视频播放与章节测验答题。

## 它做什么

给一个 `studentstudy?chapterId=...` 的学生页面链接，技能会逐节循环：

1. 进节 → 回顶 → 点播放器文档节点拿焦点 → 按 `Space` 起播
2. 轮询到「任务点已完成」（或播放中弹出的插播题，原地作答后继续播）
3. 视频播完 → 点页面顶部「章节测验」切到习题页
4. 截图读题并作答（题干有字体反爬，只能看图）
5. 点「提交」→ 弹窗出现即点确认
6. 滚到底点「下一节」，进入下一节并起播

**导航只走页面内按钮**（顶部「章节测验」+ 底部「下一节」），**不点右侧目录**——实测曾因点目录跳节，漏做了一节只允许作答一次的测验。

**上一节视频达标 → 下一节开始播放，中间环节目标 ≤20 秒**（不含看视频、不含得分验证）。

每节完成后汇报一行结果，例如 `2.1 ✅ 15.3s`；超 20s 标 ⚠️ 并注明卡在哪一步。

## 前置条件

- 已在**自己的浏览器**里打开课程页面并完成登录（技能不会新开浏览器、不会接管调试端口）
- **浏览器必须在前台**：不在前台时坐标点击会被静默吞掉，技能会先执行
  `(New-Object -ComObject WScript.Shell).AppActivate($PID)` 激活窗口
- 视频播放期间不能最小化，否则学习通会自动暂停
- 依赖 computer-use MCP（Windows 桌面操作）

## 安装

把本仓库的 `SKILL.md` 放到 TRAE 的全局技能目录：

```powershell
# Windows（Trae CN）
git clone https://github.com/LyricQing/chaoxing-auto-study.git "$HOME\.trae-cn\skills\chaoxing-auto-study"
```

目录结构必须是 `<技能根>/chaoxing-auto-study/SKILL.md`，且 `name` 字段与目录名一致。

## 使用

直接在对话里发课程链接并说明意图即可，技能会自动加载：

```
https://mooc1.chaoxing.com/mycourse/studentstudy?chapterId=...&courseId=...
调用 chaoxing-auto-study，帮我刷这节课
```

也可以显式点名：`/chaoxing-auto-study` 或「用 chaoxing-auto-study 继续刷 2.1」。

## 实现要点

- **前台优先**：每个脚本开头先 `AppActivate`；树里出现 `not the focused window` 立即中止本块，绝不在未聚焦时点坐标
- **免截图点击**：目录项、「章节测验」胶囊、播放器文档都是无障碍树节点，按 `element_id` 点击即可，不需要截图
- **Space 起播**：点播放器文档节点给焦点后按 `Space`，比按坐标点播放按钮可靠得多
- **单次 Exec ≤60s**：长等待拆块，块间只输出一行状态；禁止一次调用里又长等又读多屏题
- **读题缩放**：默认 100%；题多时缩到 80%（圆圈 x≈131、行距 40px），50% 只用于题 ≤3 且行距能精确读出
- **确认不犹豫**：弹窗出现立即点确认，不截图、不思考
- **不复盘分数**：测验只允许作答一次，提交后直接下一节，得分只在用户明确要求时回看
- **ESC 即停**：读到 `stopped by the user` 立刻终止并汇报，丢弃正在跑的长等待块

## 已实测的坑

| 现象 | 原因与处理 |
|---|---|
| 点了没反应 / 树里有 `not the focused window` | Edge 不在前台。先 `AppActivate($PID)` 再操作 |
| 播放起不来 | 点播放器文档节点拿焦点，再按 `Space`；坐标点播放按钮常失效 |
| 页面停在内容中部、看不到顶部胶囊 | 先 `Ctrl+Home`，不行再用 `scroll` 向上 |
| `Ctrl+End` / `PageUp` 对内容区无效 | 滚动统一用 `scroll` 工具（窗口根 `element_id: "0"`）或 `PageDown` |
| 坐标点击静默失效 | 最近一次 `get_app_state` 必须带过截图；翻屏/加载后重新截图 |
| 点选项后页面自己位移、后续连点全失效 | 缩放 <100% 时点中会「滚动到焦点」。一次截图只点一道题，点完立刻重拍 |
| 习题页题干是乱码 | 字体反爬（「甲午海战」→「懪午懮战」），只能截图读 |
| 点选项没选中也不报错 | 圆圈 x≈161（100%）、x≈131（80%）；点偏只会静默漏答 |
| 播放中弹出题目、视频暂停 | 不换页，原地作答，答完按 `Space` 继续 |
| 回到任务点已绿的旧节，弹窗又出现 | 那节插播题没答，先补答再播放 |
| 提交被「还有未做完的题」拦下 | 选项点偏了。点「取消」回去补选，不要强提交 |
| 提交弹窗等不到（想用文本树判定） | 弹窗文字不进无障碍树，只能看截图 |
| 想验证得分 | 不需要。只允许作答一次，复盘无收益，直接下一节 |
| 用户按 ESC | 立即停止并汇报进度，丢弃当前长等待块，不得重试同一操作 |

## 注意

- 本技能假设题目可由课程内容推断答案，不保证 100% 正确；错题只记录在「已确认答案」表里避免重犯，不会重复提交
- 请遵守所在学校的学术规范，仅用于个人学习辅助
- 视频仍有最低观看时长要求，跳过等待也只能在平台判定达标后进行
