# chaoxing-auto-study

超星学习通「视频 + 章节测验」自动化。基于浏览器扩展直接操作 DOM，
不依赖截图、坐标和计算机视觉。

> 仅供个人学习辅助，请遵守所在学校的学术规范与平台协议。

## 它解决什么问题

超星的章节测验做了字体反爬：把题干里的部分汉字换成形近假字
（「二战」渲染成「二岣」），无障碍树和 `textContent` 拿到的都是假字。
传统做法是截图让模型「看」，慢且会读错。

本项目从页面内嵌字体反解字形映射，还原明文；再按题库或模型作答。

## 组成

```
extension/          浏览器扩展（Edge / Chrome，MV3）
  src/decoder.js      字体反混淆：cmap + 字形位图匹配
  src/extract.js      题目抽取（.TiMu / .num_option_dx / #answer<qid>）
  src/content.js      解码 → 题库 → AI → 填入 → 校验 → 提交
  src/nav.js          顶层看门狗：状态判定、弹窗处理、跳节
  src/video.js        起播、失焦续播、任务点检测
  assets/             思源黑体 GB2312 子集（解码参考字库）

skill/chaoxing-answer/  答题桥（本地 HTTP 服务）
  server.mjs          收题 → 调模型 → 返答案字母
  SKILL.md            契约、配置、限制

probes/             开发期探针与字体分析脚本
docs/               设计、实测记录、路线
```

## 快速开始

**1. 装扩展**

`edge://extensions` → 开发人员模式 → 加载解压缩的扩展 → 选 `extension/`

**2. 起答题桥**

```bash
cd skill/chaoxing-answer
cp config.example.json config.local.json   # 填入你的 apiKey
node server.mjs
```

Windows 可直接双击根目录的 `start-bridge.bat`。
验证：<http://127.0.0.1:8765/health>

**3. 打开课程**

进入 `studentstudy` 页面，右上角出现导航条：

- `自动：开` —— 逐节推进（视频 → 测验 → 提交 → 下一节）
- `AI 补答：开` —— 题库未命中时调用模型

## 关键设计

| 问题 | 做法 |
|---|---|
| 题干/选项被换字 | 同字在「页面字体」与「参考字体」下渲染比对，差异大即判定被替换，再按字形最近邻还原 |
| 选项顺序可能被打乱 | 按选项文本匹配，不按位置 |
| 作答是 toggle | 先读选中状态，再决定是否点击 |
| 交卷不可逆 | 提交前校验所有 `#answer<qid>` 非空；结果页以「我的答案」为交卷铁证 |
| 单点失败拖死流程 | 任何异常 10 秒内无法推进即跳过并记账，流程不停 |

## 已知限制

- 只覆盖 GB2312 的 6763 字，生僻字会保留原样并标注
- 题库靠使用积累，新题依赖 AI；模型答错无法挽回（章节测验只能交一次）
- 视频仍需真实时长，后台播放依赖浏览器策略
- 平台改版会导致选择器失效，需更新 `extract.js` / `nav.js`
