# chaoxing-auto-study

一个 TRAE 技能（Skill），用 computer-use 驱动**你自己已登录的浏览器**，自动完成超星学习通（mooc1.chaoxing.com）的课程视频播放与章节测验答题。

## 它做什么

给一个 `studentstudy?chapterId=...` 的学生页面链接，技能会逐节循环：

1. 进入小节并开始播放视频
2. 轮询进度，达到 90%（或出现「任务点已完成」）即停止等待，不必看完
3. 切换到「章节测验」标签
4. 一次性读取全部题目并作答
5. 提交、确认、验证得分
6. 进入下一节

每节完成后汇报一行结果，例如 `1.8 ✅ 100分`。

## 前置条件

- 已在**自己的浏览器**里打开课程页面并完成登录（技能不会新开浏览器、不会接管调试端口）
- 视频播放期间浏览器需保持前台，否则学习通会自动暂停
- 依赖 computer-use MCP（Windows 桌面操作）

## 安装

把本仓库的 `SKILL.md` 放到 TRAE 的全局技能目录：

```powershell
# Windows（Trae CN）
git clone https://github.com/LyricQing/chaoxing-auto-study.git "$HOME\.trae-cn\skills\chaoxing-auto-study"
```

目录结构必须是 `<技能根>/chaoxing-auto-study/SKILL.md`，且 `name` 字段与目录名一致。

## 使用

直接在对话里发课程链接并说明意图即可，技能会自动加载：

```
https://mooc1.chaoxing.com/mycourse/studentstudy?chapterId=...&courseId=...
调用 chaoxing-auto-study，帮我刷这节课
```

也可以显式点名：`/chaoxing-auto-study` 或「用 chaoxing-auto-study 继续刷 1.9」。

## 实现要点

- **进度读取**：不走截图 OCR，直接读 UI 树的 `进度小节` 滑块值，稳定且快
- **等待策略**：全部改为条件轮询（400ms 间隔），命中特征立即继续，避免固定 sleep 空等
- **坐标优先**：该站点控件多为坐标热区，`element_id` 点击常无效，统一用窗口根 `element_id: "0"` + 截图坐标
- **答题节奏**：一屏读完所有题 → 逐个点选并当场确认圆圈变实心 → 提交。点偏不会报错，只会静默漏答

## 已实测的坑

| 现象 | 原因与处理 |
|---|---|
| 纯视频模式下标签栏消失 | 依次试刷新 → 「返回课程」→ 切相邻小节再切回；每步都要截图确认胶囊标签可见 |
| `waitFor` 误报成功 | 无障碍树里存在隐藏节点（纯视频模式下的 `章节测验` 标签），可见性判断一律以截图为准 |
| 提交被「还有未做完的题」拦下 | 选项点偏了。点「取消」回去补选，不要强提交 |
| 提交弹窗等不到 | 弹窗文字不进无障碍树，`waitFor` 无效，点完等约 1.2 秒直接截图 |
| 视频中途暂停 | 浏览器失去焦点或被最小化，切回前台点播放即可 |
| 截图变成一小块 `javascript:void(0);` | 同进程小弹层干扰，调用时显式传主窗口 `windowId` |
| 用户按 ESC | computer-use 立即终止，技能会停下并汇报进度 |

## 注意

- 本技能假设题目可由课程内容推断答案，不保证 100% 正确；出现错题只会记录，不会重复提交
- 请遵守所在学校的学术规范，仅用于个人学习辅助
- 视频仍有最低观看时长要求，跳过等待也只能在平台判定达标后进行
