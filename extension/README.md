# 学习通题目明文（v0.7）

把章节测验里被 `font-cxsecret` 混淆的题干还原成明文，显示在页面右下角；
按题库自动填入选项；自动模式下可连续跑完视频、测验与跳节。

## 为什么需要它

超星用自定义字体把题干里的部分汉字换成形近假字（「二战」显示成「二岣」），
无障碍树里拿到的也是假字。这个扩展解析内嵌字体、用字形比对还原每个假字。

## 安装

1. `edge://extensions`（Chrome 用 `chrome://extensions`）
2. 打开「开发人员模式」
3. 「加载解压缩的扩展」→ 选择本目录

> v0.3 新增了 `storage` 权限。重载后如果 Edge 提示需要重新授权或把扩展停用，
> 在扩展页重新启用即可。

## 使用

打开章节测验页，右下角出现面板。

| 情况 | 面板显示 | 你要做的 |
|---|---|---|
| 新题 | 灰色「新题」 | 在页面上点选答案 → 点面板里的「记住当前选择」 |
| 题库命中 | 绿色「自动填入」 | 核对选项是否正确，然后自行提交 |
| 填了但没写进去 | 红色「需检查」 | 看底部提示，不要提交 |

记住的答案按「解码后的题干 + 选项文本」做指纹存进本地，换页面、换章节都有效；
选项顺序被打乱也仍能匹配。

**扩展不会点提交按钮。**

## 原理

1. 从 `style#cxSecretStyle` 取出 base64 TTF，解析 cmap 得到假字符集合
2. 页面字体把假字渲染到 canvas，裁切归一化为 32×32
3. 内置思源黑体子集渲染 GB2312 全部 6763 字，同样归一化
4. 最近邻匹配；前两名太近时用 64×64 高分辨率在候选内复核
5. 判据用「与次优的差距」而不是绝对距离——复杂字距离天然偏高

## 已知限制

| 限制 | 说明 |
|---|---|
| 首次建索引 3–4 秒 | 每页一次；页面刷新后重建 |
| 只覆盖 GB2312 的 6763 字 | 生僻字解不出，标红显示原字 |
| 低置信字 | 标橙色虚线，建议人工核对 |
| 题库靠人工积累 | 尚未接 LLM；不认识的题一律标「新题」 |

## 自动模式（v0.7）

导航条上的「自动：关/开」按钮。打开后从当前节一路往下跑，遇到问题**不停机，跳过继续**：

| 情况 | 动作 |
|---|---|
| 视频任务点已完成 | 转去该节测验；无测验则直接下一节 |
| 题目有答案记录 | 自动填入并校验 |
| 有题没有答案 | 记入跳过记录 → 关弹窗 → 下一节（不提交空卷） |
| 平台提示「还有未做完的题」 | 记入跳过记录 → 取消 → 下一节 |
| 提交后未见完成状态 | 记入跳过记录 → 下一节 |
| 连续处理超过 80 节 | 停下，防止 next 被反复点击 |

**唯一不会跳过的是「空卷提交」**：章节测验只允许作答一次，交空卷等于永久丢掉这次机会，而跳过还能回头补。这一条不做成开关。

面板底部的「跳过记录」会把被跳过的节复制到剪贴板（含 chapterId 与原因），补完后再回去做。
