# v1 改造方案（已定路线）

- 日期：2026-10-29
- 依据：`analysis-2026-10-29.md`
- 已定决策：**L1 浏览器内 DOM 驱动** · **题库优先 + LLM 兜底** · **Phase 0 先验证**

---

## 1. 为什么是这三条

| 决策 | 理由 | 放弃的替代项 |
|---|---|---|
| L1 扩展 / 用户脚本 | 能读明文题干、按选择器定位、写入后可断言、可后台跑；且不违反原技能"不新开浏览器、不接管调试端口"的约束 | L0 坐标驱动（参数空间不封闭）；L2 Playwright（与约束冲突，需处理 webdriver 指纹）；L3 协议级（检测面最高、需持续逆向签名） |
| 题库优先 + LLM 兜底 | 题干指纹命中即答，正确率随使用单调上升；LLM 只做冷启动与长尾，且用文本而非图像，成本与误差都降一个量级 | 纯 LLM（无积累、同题两次结果可能不同）；纯人工（失去自动化意义） |
| Phase 0 先验证 | 三个假设任一不成立都会改变架构，"先写代码再发现"是最贵的错 | 直接开 MVP |

## 2. Phase 0：三个假设

时间盒：**1–2 小时**。产出是一份结论，不是代码。

### P0-A 字体可解性

**假设**：页面内能拿到 `style#cxSecretStyle` 的 base64 TTF，并还原出明文题干。

分两步：

1. **取证**（5 分钟）：跑 `probes/phase0.js`，确认 `#cxSecretStyle` 存在、base64 长度、`.font-cxsecret` 文本形态。
2. **解码验证**（30–60 分钟，离线）：用 fontTools 解析拿到的 TTF，检查 `cmap` 与 `glyf` 是否完整；再从公开参考字体（Noto Sans SC / 思源黑体）生成「字形轮廓哈希 → Unicode」表，对页面字体做匹配，统计命中率。

判定：

> **实测已通过：17/17，题干全通**，详见 `phase0-results.md`。字体为思源黑体子集，一页一张表，cmap 仅 17 项。

- ✅ 命中率 ≥ 99%，且解出的语料是通顺中文 → 全量走明文
- ⚠️ 命中率 80–99% → 明文为主，未知字降级截图，不静默猜
- ❌ 无法匹配 → 回退"截图读题 + 元素点击"，仍保留断言与后台能力（收益减半）

> 注意：不要直接复用第三方 `table.json`。字形表有版本与再分发许可问题，自建一次的成本远低于踩坑成本。

### P0-B 元素点击可写入

**假设**：`li[qid].click()` 能触发 `addChoice`，并把值写进 `input[name="answer<qid>"]`。

跑 `__probeClick()`：记录 `before` / `after` / `changed`。**跑完按 F5 丢弃未提交选择。**

判定：

- ✅ `changed === true` → 用元素点击，彻底摆脱坐标
- ❌ 不写入 → 改 `dispatchEvent(new MouseEvent('click',{bubbles:true}))` 或直接操作 input + 触发 change；成本略升，路线不变

### P0-C 后台视频是否计时

**假设**：切到其他标签页后，视频仍在推进（或 pause 后自动 `play()` 可维持）。

跑 `__probeC('start')` → 切到别的标签 90 秒 → 回来 `__probeC('end')`，看 `playingRatio`（≈1 表示正常推进，≈0 表示被暂停）。

判定：

- ✅ ratio ≥ 0.9 → 真后台，完全无人值守
- ⚠️ ratio ≈ 0 但 `pause` 事件可被 `play()` 救回 → 监听 pause 自动续播，仍不需前台
- ❌ 彻底停摆 → 用"专用窗口不最小化"，不占鼠标键盘、不耗 LLM 轮次，但不是完全无人值守

### 判定矩阵

| A 字体 | B 点击 | C 后台 | 结论 |
|---|---|---|---|
| ✅ | ✅ | ✅ | 全量 L1，可无人值守 —— 目标形态 |
| ✅ | ✅ | ❌ | L1 全量，改"专用窗口挂机"；其余收益不变 |
| ✅ | ❌ | — | 混合：明文读题 + 坐标提交 + 提交前断言 |
| ❌ | ✅ | — | 保留截图读题，其余全部升级；收益减半但仍优于现状 |

**三种"部分失败"都不影响主线，只影响体验上限。** 这是选 L1 而不是 L3 的另一个理由：失败可降级，不会推倒重来。

## 4. Phase 2：L1 MVP

### 4.1 模块

| 模块 | 职责 | 关键约束 |
|---|---|---|
| `frame-locator` | `studentstudy → knowledge/cards → work → frame_content` 四层定位 | 只走同源帧，跨域即报错不猜 |
| `text-decoder` | `#cxSecretStyle` → TTF → cmap/glyf → 明文 | 必须返回 `status: plain/decoded/partial/unsupported`，未知字显式列出 |
| `question-extractor` | `.questionLi` → `{qid, type, stem, options, selected}` | 题型取自 `TiMu[data]`，不从文字猜 |
| `answer-engine` | 题库指纹检索 → 未命中转 LLM 文本作答 | 低置信度挂起，不自动提交 |
| `filler` | `li[qid].click()` → 断言 input → 全量校验 → 提交 | 每个写操作后必须校验，失败即停 |
| `video-keeper` | 监听 `pause` 自动续播 | 不改倍速 |
| `progress-store` | 章节状态、答案、得分 | 幂等：重复执行不产生副作用 |
| `audit-log` | 每题原文/答案/置信度/结果 | 可回溯，便于事后定位 |

### 4.2 数据模型草案

`progress.json`

```json
{
  "version": 1,
  "courseId": "268570790",
  "clazzid": "158295548",
  "chapters": {
    "1221810778": {
      "title": "3.5 国防（军事）战略【下】",
      "video": "done",
      "quiz": { "status": "submitted", "score": 100, "at": "2026-10-29T12:00:00+08:00" }
    }
  }
}
```

`qbank.jsonl`（一行一题，便于追加）

```json
{"hash":"<sha1(type+stem+options)>","type":1,"stem":"…","options":["…"],"answer":["A","B","C"],"source":"manual","confidence":1.0,"hits":3}
```

### 4.3 三条设计原则

1. **动作必须可断言**——写操作后校验状态，失败即停，不猜。
2. **状态必须落盘**——任何时刻可从磁盘恢复，重复执行幂等。
3. **agent 退出执行环**——扩展自主跑，agent 只在异常时介入。这把"上百次 LLM 往返"压成"1 次启动 + 少量异常"。

## 5. 验收标准

单章 5 节无人值守跑完，满足：

- 静默失败 **0 次**（每次点击都有断言）
- 答题正确率 **不低于** 现有水平（现状有 2 次错答）
- 全程 **不占用鼠标键盘**
- 单节间切换 **≤ 5 秒**
- 异常可恢复：中断后重跑不产生重复提交

## 6. 边界（不做）

- 不接**考试**，只做章节测验与视频任务点
- 不改**倍速**、不伪造进度上报

## 7. 风险与回退

| 风险 | 触发信号 | 回退动作 |
|---|---|---|
| 字体表覆盖不足 | `partial` 比例 > 5% | 未知字降级截图，人工确认后入库 |
| 页面改版 | 选择器连续失败 | 选择器集中在单个 adapter 文件，改一处生效 |
| 扩展被识别 | 出现人机校验页 | 停用扩展，改走 L2 旁路；不重试 |
| 平台判定异常 | 任务点不计入 | 立即停手，人工核对后台学时 |

## 8. 执行步骤（探针自动落盘到 Downloads）

`probes/phase0.js` 会自己把结果下载成 JSON，不需要复制粘贴。

| 步 | 操作 | 产出 |
|---|---|---|
| 1 | 打开「章节测验」页 → F12 → Console → 粘贴脚本全文 → 回车 | `phase0-questions-<ts>.json` |
| 2 | 同一页输入 `__probeClick()` → 回车，看到结果后**立刻 F5** | `phase0-click-<ts>.json` |
| 3 | 打开同节视频页 → 再粘贴一次脚本 → `__probeC('start')` → 切标签页等 90 秒 → `__probeC('end')` | `phase0-video-<ts>.json` |

- 第 2 步会勾选一个选项，**不要点提交**，跑完 F5 即丢弃。
- 浏览器若提示「允许多个下载」，点允许。
- 下载失败时用 `copy(JSON.stringify(__probeResult))` 手动复制。

### DevTools 拒绝粘贴怎么办

首次往 Console 粘贴代码时，Chrome/Edge 会拦截并要求手动键入 `allow pasting`——这是 self-XSS 防护，不是错误。

两种处理：

| 方式 | 操作 | 适用 |
|---|---|---|
| 放行 | 在 Console 里**手动逐字符键入** `allow pasting` 后回车（切英文输入法，不能粘贴、不能用联想） | 一次性，之后该 profile 不再拦 |
| 绕开（推荐） | Sources 面板 → Snippets → New snippet → 粘贴 → `Ctrl+Enter` 运行 | 脚本会保存，换页面重跑只需再按 `Ctrl+Enter`，正好匹配本流程要跑三次的场景 |

### 提示「没有 .questionLi」怎么排查

v2 及以前会把粘贴那一刻的 DOM 快照缓存起来，题目帧稍后加载就会误判。v3 已改为每次调用重新采集。若 v3 仍报找不到：

1. 先跑 `__probeScan()`，看三张表：可访问帧、无法访问的帧、iframe 清单。
2. **有「无法访问的帧」** → Console 左上角 context 下拉框切到该帧；或把该帧地址单独开标签页再跑。
3. **有「疑似题目帧」但计数为 0** → 题目还没渲染，点进具体测验等出现题目再 `Ctrl+Enter`。
4. **两者都没有** → 当前页不是测验页（可能停在章节列表/成绩页/视频页）。
